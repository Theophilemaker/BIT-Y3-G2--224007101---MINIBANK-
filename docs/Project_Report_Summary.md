# Project Report Summary

## Abstract
MiniBank Rwanda is a comprehensive,  online banking simulation system developed using Core PHP, MySQL, and  JavaScript. The system was designed to demonstrate secure financial workflows, emphasizing database integrity through ACID transactions, role-based access control, and a modern, responsive user interface. It provides a realistic environment for customers to manage accounts and for administrators to oversee banking operations.

## Objectives Achieved
1. Developed a secure authentication system using Bcrypt hashing and CSRF protection.
2. Implemented a functional banking engine capable of handling deposits, withdrawals,views account balances,views transaction history,statements and transfers using double-entry accounting.
3. Built a responsive,  UI and U/E matching modern banking standards.
4. Created a centralized Admin Panel for full system management (Users, Accounts, Settings among others).
5. Ensured financial integrity by utilizing PDO transactions and row locking to prevent race conditions.

## Conclusion
The MiniBank Rwanda project successfully demonstrates the practical application of software engineering principles. It proves that a robust, secure financial application can be built using core web technologies without relying on heavy frameworks. The system is scalable, maintainable (thanks to the MVC architecture), and ready for further academic exploration (such as integrating real SMS gateways or biometric authentication).
